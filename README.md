# DataVision – Data Analytics Platform

**Turn Your Data Into Meaningful Insights.**

DataVision is a Python-based data analytics platform that helps users upload datasets, explore data, clean information, create interactive visualizations, and discover useful insights.

## About the Project

DataVision is designed to make data analysis easier through a simple and user-friendly interface. Users can upload CSV and Excel files, examine their datasets, handle missing values, apply filters, and generate different types of charts.

## Features

- **Data Upload:** Upload CSV and Excel datasets.
- **Dataset Overview:** View rows, columns, missing values, and duplicate records.
- **Data Preview:** Explore uploaded datasets.
- **Data Cleaning:** Handle missing values and remove duplicate records.
- **Data Filtering:** Filter data using numerical and categorical columns.
- **Data Visualization:** Generate interactive charts and graphs.
- **Smart Insights:** Discover useful information and patterns from datasets.
- **Download Reports:** Download cleaned datasets and analysis reports.

## Technologies Used

- Python
- Flask
- Streamlit
- Pandas
- Plotly
- HTML
- CSS


## How to Run the Project

### 1. Install the required libraries

```bash
pip install flask streamlit pandas plotly openpyxl
```

### 2. Run the Flask application

```bash
python app.py
```

Open this address in your browser:

`http://127.0.0.1:5000`

### 3. Run the Streamlit dashboard

Open another terminal in the project folder and run:

```bash
streamlit run dashboard.py
```

Open:

`http://localhost:8501`

## Project Objective

The main objective of DataVision is to provide an easy-to-use platform where users can explore, clean, analyse, and visualize datasets without needing complicated tools.
